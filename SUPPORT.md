# Support

This project has **Tier 2 Fastly open-source support**.

It is maintained on a best-effort basis. Maintainers may review bug reports and pull requests as time permits, but response times and fixes are not guaranteed. This project is not covered by a Fastly customer support SLA.

For usage questions, bug reports, and feature requests, open a GitHub issue. Before filing an issue, check the existing issues and include enough detail to reproduce the behavior.

For vulnerabilities or other security-sensitive reports, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
